# DSH AstriaX Native 0.3.3

- Native AstrBot and NapCat instance manager with lifecycle, logs, config editing and backups.
- Embedded AstrBot dashboard and NapCat WebUI proxy.
- OneBot pairing, QQ login helpers and native QQ bridge.
- DSH provider adapter with AstrBot persona/memory/mood context.
- AstrBot tool gateway for registered tools, with shell/Python/file tools filtered by default.
- QQ session panel with transcripts, per-session workspaces, clear and send controls.
- User-selectable QQ workspace with Windows folder picker and Unicode-safe path handling.
- Automatic bridge startup and generated shared `qq` DSH profile.
- Console-window suppression for AstrBot local shell and restart subprocesses.

Python, AstrBot and NapCat runtimes are downloaded on first use and are not bundled.
